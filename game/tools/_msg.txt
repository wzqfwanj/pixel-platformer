修移动后蓄力失效：跨台阶 + 掉落检查顺序

用户反馈：原地能一直释放，一旦移动就没了。查出两个叠加的 bug：

1. 没有自动跨台阶
   移动只有横向位移，撞到 1 格高的台阶就贴墙停下（vx 在 0/25 之间每帧抖）。
   实测卡在 x≈412，那里一列 groundY=17、下一列 groundY=16，正好差一格。
   修法：moveWithCollision 里撞墙时先试"抬高一格再走"（仅贴地时），
   能过就爬上去。这是横版游戏的标配能力。

2. 掉落检查在所有提前 return 之后
   update() 里蓄力 / 爆炸动作 / 冲刺 / 攻击 四个分支都提前 return，
   而"掉出地图"的检查在函数末尾 —— 只要在这些状态下掉坑，
   角色会无限下坠（实测 feet 掉到 1022，地图高才 352），蓄力条一直挂着。
   修法：把掉落检查提到 update 最前面（所有 return 之前），
   并且掉落时清掉 charging / charge / slash。

另外修了 deploy 的版本标记：
   原来用 git 短哈希，未提交的改动不改变哈希，部署后无法确认是否生效
   （实际发生过一次：改了 main.js 但 build 号没变，误以为部署成功）。
   现在 build id 用精确到秒的时间戳 + 哈希（未提交时带 + 号）。

验证：
   本地 30 秒推进 3183px 到终点（修复前卡在 x=910）
   线上按住 K 边跑 30 秒释放 23 次，玩家 feet=256 正常
   新增回归测试：第 19 项（跨台阶）、第 20 项（蓄力时掉坑）
