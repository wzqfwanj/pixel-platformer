排除"加载了旧代码"，并把状态做成可见

上一轮加了兜底但没能复现用户描述的现象。这一轮做了三件事，
让问题可以自己"说话"：

1. 构建标记（core/build.js）
   - tools/gen-build.mjs 生成 git 短哈希 + 时间戳
   - HUD 左下角常驻显示，调试信息里也有完整 BUILD label
   - 用途：如果用户看到的是旧 hash，说明浏览器缓存了旧文件，
     那就不是代码 bug。这是排查"改了不生效"最快的一步。

2. 蓄力释放计数
   - main.js 每帧检测 slash 从无到有，累加 game.releaseCount
   - F1 调试信息显示 RELEASED N TIMES
   - 用户可以自己看：按 K 10 次，如果计数是 10 就是正常释放了
     （只是视觉没注意到），如果卡在 1 就确实没释放

3. 一键部署 tools/deploy.mjs
   - 更新 build → 打包 → 上传 → 重启 → 拉线上 build.js 比对
   - 避免"忘记更新版本号"或"部署漏了文件"

顺带修一个真实缺陷：
   通关或无尽模式死亡后 game.won = true，主循环第 246 行
   `if (!game.won) p.update(...)` 就不再更新玩家。
   如果此时玩家按着 K、蓄力条处于半满，条会画出来但永远不动。
   现在进入 won 状态时调用 clearPlayerAttack() 清掉蓄力状态。

线上验证（verify-build-live.mjs）：
   - 左下角 build 标记可见
   - 按住 K 12 秒释放 13 次，最久"满了不释放" 0 帧
